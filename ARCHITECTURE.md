# RectlessOS: архитектура флешки

RectlessOS основана на Linux (Ubuntu 24.04) и работает прямо с флешки.
Всё делится на три зоны, как в твоей схеме: **sys**, **root**, **user**.

```
Флешка 64 ГБ (таблица GPT)
│
├── [1] bios-boot            8 МБ    служебный раздел для загрузки в старом BIOS
│
├── [2] RECTLESS  (FAT32)   ~2 ГБ    ══ sys ══  система, только чтение
│   ├── EFI/BOOT/BOOTX64.EFI          загрузчик для UEFI
│   ├── RectlessOS.ico, autorun.inf   значок флешки в Windows
│   └── RectlessOS/
│       ├── README.txt                описание схемы
│       └── sys/
│           ├── vmlinuz               ядро Linux
│           ├── initrd                начальная загрузка
│           ├── filesystem.squashfs   вся система одним сжатым образом
│           └── boot/grub/            меню загрузки (grub.cfg) и модули
│
├── [3] casper-rw (ext4)    16 ГБ    ══ root ══  слой администратора
│   └── upper/                        все изменения системы: настройки (/etc),
│                                     установленные программы (apt), службы
│
└── [4] home-rw   (ext4)    ~46 ГБ   ══ user ══  твои файлы
    └── user/                         домашняя папка: Документы, Загрузки, рабочий стол,
                                      настройки программ (в /home/user)
```

> Если систему записать готовым образом флешки (`tools/make-image.sh`, 14 ГБ), то root будет 6 ГБ,
> а user при первом запуске сам растянется на всё оставшееся место флешки.

## Что за что отвечает

| Зона | Что внутри | Можно ли ломать |
|------|-----------|-----------------|
| **sys** | ядро, загрузчик, готовый образ системы | Нет. Только чтение, система никогда не меняется. Обновление RectlessOS = замена этой папки |
| **root** | то, что ты поменял в системе: пароли, сеть, `sudo apt install ...`, настройки служб | Можно: если что-то сломал, очисти этот раздел (форматирование `casper-rw`), и система станет как новая. Файлы user останутся |
| **user** | личные файлы и настройки программ | Это твои данные, их стоит копировать в резерв |

Как это собирается в работающую систему при загрузке:

```
sys (squashfs, только чтение)  ─┐
                                ├─ overlay ─►  /  (корень системы)
root (casper-rw, запись)       ─┘
user (home-rw)                 ─────────────►  /home
```

Преимущества такой схемы: система защищена от поломок (sys read-only), «сброс до заводских»
не стирает личные файлы (чистим только root), а обновить систему можно, не трогая данные.

## Меню загрузки

1. **Start (saves root + user on the USB drive)** — обычный запуск, всё сохраняется.
2. **Guest mode** — ничего не сохраняется (для чужого компьютера).
3. **Safe graphics (nomodeset)** — если на экране чёрный экран или артефакты.
4. **Load into RAM** — система целиком копируется в память, флешку можно вынуть.

## Вход в систему

Пользователь `user`, пароля нет, вход автоматический. `sudo` работает без пароля.
Раскладка: English / Русский, переключение Alt+Shift.

## Ограничения (честно)

* Это live-система на Ubuntu 24.04 с XFCE. Таскбар и оформление из твоего макета
  (внизу панель с поиском и иконками) в эту версию пока не перенесены: сейчас
  стандартная панель XFCE, твой логотип и фиолетовый фон.
* Установка на диск компьютера (как у Windows) пока не предусмотрена: система живёт на флешке.
* Для Wi-Fi и видеокарт нужны драйверы; прошивки (`linux-firmware`) включены,
  проприетарные драйверы NVIDIA нет (работает открытый nouveau).
* На компьютерах с включённым Secure Boot загрузчик нужно разрешить или Secure Boot отключить
  (загрузчик не подписан).
