# RectlessOS 0.2.2

Своя ОС на базе Linux (Ubuntu 24.04 + XFCE), которая запускается прямо с флешки на реальном ПК
(UEFI и старый BIOS). Схема флешки: **sys** (система) / **root** (настройки и программы) /
**user** (твои файлы) — см. [ARCHITECTURE.md](ARCHITECTURE.md).

## Что в папке

| Файл | Зачем |
|------|-------|
| `build.sh` | собирает ISO с нуля (Ubuntu/Debian или WSL2, от root) |
| `tools/make-image.sh` | делает из ISO готовый образ флешки `.img` (для Windows: пишется Etcher/Rufus) |
| `tools/write-usb.sh` | записывает ISO сразу на флешку по схеме sys/root/user (Linux) |
| `tools/bios-embed.py` | ставит загрузчик для старого BIOS (вызывается скриптами выше) |
| `config/` | списки пакетов (что входит в систему) |
| `overlay/` | файлы, которые кладутся в систему: обои, автовход, раскладка, язык, авторасширение user |
| `assets/` | `RectlessOS.ico` и логотип |
| `.github/workflows/build.yml` | облачная сборка образа флешки на GitHub, если Linux нет |

## Путь для Windows (образ флешки готовится в облаке)

1. Создай репозиторий на github.com и загрузи в него содержимое этого архива (распакованное).
2. Вкладка **Actions** → **Build RectlessOS** → **Run workflow**. Через 10-20 минут внизу страницы запуска
   появится артефакт `RectlessOS-flash-image` (внутри `RectlessOS-0.2.2.img.xz`, около 1,5 ГБ).
3. Скачай, распакуй zip. Открой `RectlessOS-0.2.2.img.xz` в **balenaEtcher** (распаковывать не надо)
   или в **Rufus**, выбери флешку, запиши. Флешка будет полностью стёрта.
4. При первом запуске раздел user сам растянется на всю флешку.

## Путь для Linux или WSL2

```bash
sudo bash build.sh                                           # даёт out/RectlessOS-0.2.2-desktop.iso
sudo apt install gdisk dosfstools e2fsprogs mtools grub-pc-bin grub-efi-amd64-bin grub-common parted xorriso python3
lsblk                                                     # найди флешку, например /dev/sdb. Ошибёшься, сотрёшь не тот диск!
sudo bash tools/write-usb.sh out/RectlessOS-0.2.2-desktop.iso /dev/sdb    # сразу на флешку
# или образом: sudo bash tools/make-image.sh out/RectlessOS-0.2.2-desktop.iso  -> out/RectlessOS-0.2.2.img
```

Размер root задаётся `ROOT_GB=24` (по умолчанию 16 ГБ при записи на флешку и 6 ГБ в образе;
всё остальное идёт под user).

## Запуск

Вставь флешку, включи ПК и открой меню выбора загрузки (обычно F12, F11, Esc или F8), выбери флешку.
В меню GRUB выбери первый пункт. Вход автоматический (пользователь `user`, без пароля).
Если Secure Boot включён, отключи его в BIOS: загрузчик не подписан.

## Параметры сборки

```bash
sudo PROFILE=minimal bash build.sh   # только консоль, для проверки
sudo OS_NAME=Name bash build.sh      # поменять название (латиницей)
```


## Что нового в 0.2.0 — оформление
- Тёмная фиолетово-чёрная тема (Rectless-dark) для окон, верхней и нижней панелей.
- Верхняя панель заменена «островком» (Dynamic Island): маленькая таблетка сверху по центру — звук, дата/время, трей, питание, выход.
- Нижняя панель — компактный тёмный док по центру: кнопка R, Файлы, Терминал, Браузер и открытые окна.
- Тёмные иконки Papirus-Dark с фиолетовыми папками, на рабочем столе только «Домашняя папка» и «Корзина».
- Маленький тёмный курсор (DMZ-Black, размер 20).
- Secure Boot по-прежнему нужно выключить (подписанный загрузчик — в планах).

## 0.2.2 — диагностика
- Через 40 с, 2 и 5 минут после старта система сама кладёт журналы на флешку: раздел `RECTLESS`, папка `RectlessOS\logs` (открывается из Windows). Нужно, если рабочий стол не стартует на каком-то железе.
- xfwm4: вертикальная синхронизация выключена (меньше риск зависаний на разных видеокартах).
- Экран входа в стиле RectlessOS: тёмная фиолетовая карточка с логотипом R на фирменных обоях.

## 0.2.2 — исправление «чёрный экран и возврат на экран входа»
- Экран входа и автовход теперь явно запускают сеанс `xfce` (`user-session=xfce`), в экране входа появился выбор сеанса.
- Для видеокарт Intel / AMD / NVIDIA (nouveau) X-сервер использует универсальный драйвер `modesetting` вместо старых драйверов, которые на части ПК роняют X при входе.
- В систему добавлены пакеты, которые из-за `--no-install-recommends` могли не поставиться (D-Bus для сеанса, `libpam-systemd`, polkit, Mesa DRI, драйверы fbdev/vesa).
- **Охранник сеанса.** Если рабочий стол умирает быстрее чем за 20 секунд после входа, система сама выбирает более щадящий режим и повторяет вход: уровень 1 — X без аппаратного ускорения, без композитинга, настройки xfce сброшены (копия в `~/.config/xfce4.broken.*`); уровень 2 — драйвер fbdev. Рабочий уровень запоминается (`/var/lib/rectlessos/gfx-level`, сбросить: `sudo rm /var/lib/rectlessos/gfx-level`).
- **Диагностика починена.** Раньше запись журналов на флешку молча не работала (раздел sys уже смонтирован только для чтения). Теперь журналы кладутся в `RECTLESS` → `RectlessOS\logs` через 15 с, 45 с, 2 мин, 5 мин и сразу при падении сеанса.
- Растягивание раздела user сдвинуто на 2,5 минуты после старта с низким приоритетом диска (не мешает входу).
- Исправлена опечатка в `theme-extra.css` (лишний `#` ломал правило скругления панелей).

## 0.2.3 — NVIDIA RTX
- В сборку добавлен проприетарный драйвер NVIDIA 550 (готовые модули ядра `linux-modules-nvidia-550-generic`, пакеты X-драйвера и OpenGL). Нужен для RTX 30xx/40xx, где открытый nouveau на ядре 6.8 часто роняет X при входе. Если драйвер в сборке не поставился, сборка продолжается с nouveau (в логе будет «ВНИМАНИЕ»).
- Подключён репозиторий `restricted` (в нём лежит драйвер NVIDIA). nouveau отключён в `/etc/modprobe.d/rectlessos-nvidia.conf`.
- Диагностика пишет версию драйвера NVIDIA.
- Версия: чтобы не путать сборки, 0.2.3.
